# ПДД Ірландії — тренажер

Це той самий тренажер, що був в одному великому HTML-файлі (6 МБ), але
розбитий на кілька невеликих файлів, щоб його можна було нормально
завантажити й переглядати на GitHub, а потім опублікувати через
GitHub Pages.

## Структура файлів

```
index.html          — головна сторінка (маленька, ~4 КБ)
style.css           — стилі
app.js              — логіка тренажера
data/chunk01.js ...  — дані питань, розбиті на 6 частин (~300 КБ кожна)
  data/chunk06.js
assets/img/*.png     — картинки до питань, кожна окремим файлом
.nojekyll             — вимикає обробку Jekyll на GitHub Pages
```

Раніше всі картинки (267 шт.) зберігались як base64-текст всередині
одного величезного JSON-блоку — саме через це файл важив 6 МБ і не
відкривався в браузерному переглядачі GitHub. Тепер кожна картинка —
окремий `.png`-файл (здебільшого 4–50 КБ), а дані питань — звичайний
текстовий JS-масив без картинок усередині.

## Як викласти на GitHub і увімкнути Pages

1. Створіть новий репозиторій на GitHub (наприклад `pdd-ireland-quiz`).
2. Завантажте вміст цієї папки в репозиторій одним з двох способів:

   **Через веб-інтерфейс:**
   - Натисніть "Add file" → "Upload files" і перетягніть усі файли й
     папки (`index.html`, `style.css`, `app.js`, `data/`, `assets/`,
     `.nojekyll`), зберігаючи структуру папок.

   **Через git (рекомендовано, надійніше для багатьох файлів):**
   ```bash
   cd site
   git init
   git add -A
   git commit -m "PDD Ireland quiz"
   git branch -M main
   git remote add origin https://github.com/<ваш-логін>/pdd-ireland-quiz.git
   git push -u origin main
   ```

3. У репозиторії відкрийте **Settings → Pages**.
4. У розділі "Build and deployment" виберіть:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/(root)**
5. Збережіть. Через 1–2 хвилини сайт з'явиться за адресою:
   ```
   https://<ваш-логін>.github.io/pdd-ireland-quiz/
   ```

## Локальна перевірка перед публікацією

Файл не можна просто відкрити подвійним кліком (`file://`), бо браузер
блокує завантаження `data/*.js` та картинок через CORS. Запустіть
локальний сервер у папці `site`:

```bash
python3 -m http.server 8000
```

і відкрийте `http://localhost:8000/`.
